# es-record

Recorder providers (the window recorder encodes with GStreamer), audio devices, input streams, project folder, recovery, and the clip export (options, trim and the ffmpeg arguments the trim viewer and `agent export` share).

May depend on: es-store, es-model, es-protocol, es-geom. Its project files are written through es-store.

Must not depend on: gpui*, es-ui, any layer-3 crate.
