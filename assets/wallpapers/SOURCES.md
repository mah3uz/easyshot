# Built-in wallpapers

`wall-1.jpg` … `wall-7.jpg` are soft mesh gradients generated by `scripts/wallpapers.py`
(Python 3 and Pillow): 2560×1440 JPEG, about 180 KB each. Run the script to rebuild them;
its fixed seeds give the same pixels each time.

They were made for easyshot and are dedicated to the public domain under CC0 1.0
(https://creativecommons.org/publicdomain/zero/1.0/).
